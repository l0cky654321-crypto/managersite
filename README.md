# Закуп — приложение для формирования заявок поставщикам

## Что изменилось в этой версии

- **Исправлен PDF** — кириллица больше не превращается в квадраты/иероглифы: в PDF встроен
  полноценный шрифт с поддержкой кириллицы (раньше использовался встроенный шрифт jsPDF,
  который умеет только латиницу). Заодно PDF стал заметно наряднее: тёмная шапка с названием
  компании и точки, чередующиеся строки таблицы, итоговая сумма в акцентной плашке, номера страниц.
- **Меньше ручного ввода**:
  - Кнопка «+» у товара сразу добавляет 1 шт — не нужно сначала печатать число.
  - У товара, который уже в списке, появляется степпер «− / кол-во / +» — количество меняется в один тап.
  - Новая кнопка **«Повторить прошлый закуп»** — подтягивает из истории последний завершённый
    закуп по выбранной точке и сразу наполняет список; остаётся только поправить количества
    и отправить. Для регулярных закупок это сводит ввод почти к нулю.
- **Удобнее находить товары** — список автоматически группируется по категориям со
  сворачиваемыми заголовками (видно, сколько товаров уже добавлено в каждой категории),
  плюс поиск с кнопкой очистки.
- **Внешний вид** — обновлённая цветовая палитра, тени, состояние загрузки, всплывающие
  уведомления (например, «Закуп завершён и сохранён»), закреплённая корзина справа.
- **Производительность** — шрифт для PDF (и сам генератор PDF/Excel) подгружается только
  в момент экспорта, а не при каждом открытии сайта, поэтому первая загрузка страницы
  осталась лёгкой несмотря на добавленный шрифт.


Выбираете точку ресторана → ищете товар → указываете количество → нажимаете «+».
Список справа группируется по поставщику и считает сумму. По кнопке формируется
готовый **Excel** или **PDF** отчёт для отправки поставщику. Каталог товаров,
поставщики, точки и шаблон имени файла настраиваются на вкладке «Настройки» —
никакого ручного набора в Excel/от руки больше не нужно.

## 1. Supabase (база данных)

1. Зайдите на https://supabase.com → создайте новый проект (бесплатного тарифа достаточно).
2. В левом меню откройте **SQL Editor → New query**, вставьте содержимое файла
   `supabase/schema.sql` из этого проекта и нажмите **Run**. Это создаст все таблицы
   (`locations`, `suppliers`, `products`, `orders` и т.д.).
3. В **Project Settings → API** скопируйте:
   - `Project URL` → это `VITE_SUPABASE_URL`
   - `anon public` ключ → это `VITE_SUPABASE_ANON_KEY`

> Схема открыта на чтение/запись по anon-ключу (это внутренний инструмент без
> публичного доступа). Если сайт будет виден посторонним — добавьте вход по паролю
> (Supabase Auth) и замените политики RLS в `schema.sql` на `authenticated`.

## 2. Запуск локально (проверить перед деплоем)

```bash
cp .env.example .env
# впишите VITE_SUPABASE_URL и VITE_SUPABASE_ANON_KEY в .env
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173). Без заполненного `.env`
приложение тоже откроется — включится демо-режим с примерами товаров, но без
сохранения (удобно, чтобы посмотреть интерфейс).

Первым делом зайдите в **Настройки** и добавьте свои точки, поставщиков и товары
(один раз) — дальше на них можно просто выбирать точку и кликать «+» на товарах.

## 3. Деплой на Netlify

**Вариант А — через сайт Netlify (проще всего):**
1. Загрузите папку проекта в GitHub-репозиторий (или перетащите папку `dist` после
   `npm run build` прямо на https://app.netlify.com/drop — это самый быстрый способ
   без Git).
2. Если через GitHub: на https://app.netlify.com → **Add new site → Import an
   existing project**, выберите репозиторий.
3. Build command: `npm run build`, Publish directory: `dist` (уже прописано в
   `netlify.toml`).
4. В **Site settings → Environment variables** добавьте `VITE_SUPABASE_URL` и
   `VITE_SUPABASE_ANON_KEY` (те же значения, что в `.env`).
5. Deploy site.

**Вариант Б — через Netlify CLI:**
```bash
npm install -g netlify-cli
netlify login
netlify init
netlify env:set VITE_SUPABASE_URL https://ваш-проект.supabase.co
netlify env:set VITE_SUPABASE_ANON_KEY ваш-anon-ключ
netlify deploy --prod
```

## 4. Как настраивается отчёт

Вкладка **Настройки → Отчёт**:
- **Шаблон имени файла** — например `ЗАКУП_{location}_{date}` даст файл
  `ЗАКУП_AFRO_16-08-2026.xlsx`. Можно убрать/переставить `{location}` и `{date}`
  или добавить свой текст.
- **Название компании** — печатается сверху PDF-отчёта.

Отчёт (и Excel, и PDF) группирует товары по поставщику — так же, как в вашей
текущей таблице: поставщик, контакты, товар, ед., шт., цена, сумма, итог по
поставщику и общий итог внизу.

## 5. Структура каталога товаров

- **Точки** — рестораны/точки (AFRO, Karina, ...).
- **Поставщики** — имя, контакты, примечание (например «оплата с кассы»).
- **Товары** — привязаны к поставщику, есть категория (для группировки, например
  «Салфетки»), единица измерения и цена.
- Если для точки не задан отдельный каталог (таблица `location_products` пустая для
  этой точки) — показываются **все** товары. Чтобы у каждой точки был свой набор
  товаров (как отдельные листы в вашем Excel), добавляйте записи в
  `location_products` — либо через SQL Editor, либо можно расширить вкладку
  «Настройки» под эту задачу отдельным шагом.

## Технологии

React + Vite, Supabase (Postgres), генерация Excel — `xlsx` (SheetJS), генерация
PDF — `jspdf` + `jspdf-autotable`. Всё построение файлов отчёта происходит в
браузере пользователя, данные о товарах не уходят никуда, кроме вашей базы
Supabase.
